# 카반하다 이미지 에셋 SSOT

## 1. 확정 기준

카반하다 차량 이미지는 GitHub 저장소의 `public/vehicles` 폴더를 원본 위치로 사용합니다.

```txt
public/
└── vehicles/
    └── 차량ID/
        ├── main.jpg
        ├── 01.jpg
        ├── 02.jpg
        └── 03.jpg
```

Google Sheet에는 원본 이미지 경로를 그대로 적습니다.

```txt
/vehicles/avante-cn7-2022/main.jpg
/vehicles/avante-cn7-2022/01.jpg
/vehicles/avante-cn7-2022/02.jpg
/vehicles/avante-cn7-2022/03.jpg
```

빌드 과정에서 `scripts/optimize-vehicle-images.mjs`가 이미지를 WebP로 변환하고, 실제 배포용 JSON은 WebP 경로를 사용합니다.

---

## 2. 권장 이미지 사이즈

| 용도 | 파일명 | 권장 사이즈 | 비율 | 설명 |
|---|---|---:|---:|---|
| 대표 썸네일 / 카드 이미지 | `main.jpg` | `1600 x 1067px` | 3:2 | 메인 카드와 상세 대표 이미지에 사용 |
| 외관 사진 | `01.jpg` | `1600 x 1067px` | 3:2 | 상세 갤러리 1번 |
| 추가 외관 사진 | `02.jpg` | `1600 x 1067px` | 3:2 | 상세 갤러리 2번 |
| 실내 / 계기판 / 옵션 사진 | `03.jpg` | `1600 x 1067px` | 3:2 | 상세 갤러리 3번 |

최소 권장 사이즈는 `1200 x 800px`입니다.  
가능하면 모든 차량 사진은 같은 비율로 맞춥니다.

---

## 3. 촬영 / 편집 규칙

- 차량이 사진 중앙에 오도록 둡니다.
- 대표사진 `main.jpg`는 전면 또는 전면 45도 사진을 사용합니다.
- 사진 비율은 3:2를 우선합니다.
- 세로 사진은 사용하지 않는 것을 권장합니다.
- 너무 어두운 사진, 흔들린 사진, 번호판이 과하게 보이는 사진은 피합니다.
- 파일명은 영문 소문자, 숫자, 하이픈만 사용합니다.
- 한글 파일명, 공백, 괄호, 특수문자는 사용하지 않습니다.

좋은 파일명:

```txt
main.jpg
01.jpg
02.jpg
03.jpg
```

피해야 할 파일명:

```txt
아반떼 사진.jpg
차량(1).jpg
KakaoTalk_2026_05_10_12_00_00.jpg
```

---

## 4. 차량ID와 폴더명 규칙

`차량ID`는 Google Sheet와 이미지 폴더명이 같이 맞아야 합니다.

예시:

```txt
차량ID:
avante-cn7-2022

이미지 폴더:
public/vehicles/avante-cn7-2022/
```

시트의 대표사진 경로:

```txt
/vehicles/avante-cn7-2022/main.jpg
```

SSOT 기준:

```txt
차량ID = 이미지 폴더명 = 상세페이지 URL 식별자
```

차량ID는 한 번 정하면 바꾸지 않는 것을 원칙으로 합니다.

---

## 5. WebP 변환 규칙

운영자는 JPG 또는 PNG만 올려도 됩니다.  
배포 빌드에서 자동으로 WebP 파일이 생성됩니다.

```txt
main.jpg -> main.webp
01.jpg -> 01.webp
02.jpg -> 02.webp
03.jpg -> 03.webp
```

Google Sheet에는 원본 경로를 적습니다.  
WebP 경로는 빌드 스크립트가 자동으로 처리합니다.

---

## 6. 모바일 갤러리 기준

상세페이지 모바일 갤러리는 이미지 한 장을 크게 보여주고, `<` `>` 버튼과 넓은 좌우 터치 영역으로 이동합니다.

- 왼쪽 30% 터치: 이전 이미지
- 오른쪽 30% 터치: 다음 이미지
- 가운데 터치: 이미지 확대 미니갤러리
- 스크롤 중에는 갤러리 전환이나 확대가 열리지 않아야 함
